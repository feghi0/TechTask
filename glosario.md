# Glosario

| Concepto | Definición |
|---|---|
| Proyecto | Conjunto de tareas perteneciente a una cuenta, con nombre y descripción. |
| Tarea | Actividad de un proyecto con materia, prioridad, estado y fecha opcional. |
| Materia | Texto que identifica la asignatura; no equivale a catálogo oficial. |
| Estado | Situación de la tarea: pendiente, en desarrollo, bloqueada o entregada. |
| Prioridad | Valor declarado baja, media o alta; no se recalcula por urgencia. |
| Dependencia | Tarea del mismo proyecto que debe estar entregada antes de entregar otra. |
| Bloqueo | Estado declarado por el usuario o impedimento del servidor para una operación; no son equivalentes. |
| Vencimiento | Fecha calendario límite; se interpreta en el calendario argentino definido. |
| Entrega | Paso a delivered permitido solo desde in_progress y con requisitos cumplidos. |
| Historial | Registro inmutable de cambios de estado anteriores/nuevos y fecha. |
| Conflicto de fechas | Acumulación de tres o más tareas no entregadas dentro de tres días calendario. |
| Urgencia | Clasificación derivada de fecha y estado; no modifica la prioridad declarada. |
| Propietario | Cuenta que puede consultar y operar sus propios proyectos y tareas. |
| Versión | Número de revisión que evita sobrescribir una edición basada en datos antiguos. |
| Baja lógica | Retiro de la tarea activa sin eliminar físicamente su registro histórico. |
